# 管理员私聊能力

这套能力**只对全局管理员（`admin.ownerUin`）的私聊**开放，用来在不打开控制台的情况下：
跨群发送、查看统一审批收件箱、查看只读状态。

## 使用前提

- 目标群必须在 `allow.groups` 里。没有单独的管理员广播白名单，避免两套名单漂移。
- 机器人必须在该群里；目标群有未核对的发送（held）时会跳过。
- 发送仍受现有 `assertCanSend` 约束：暂停、观察模式、非活跃时段会拒绝。
- 媒体只接受：
  - 管理员私聊里已有消息的 `messageId`（执行时重新取新鲜 URL）；
  - 公网 `http(s)` URL。
  - **不接受**服务器本地路径。

## 固定命令

在管理员私聊里直接发（`post_type=message`，机器人自己的回显不会触发）：

```text
发到群 433397830：今晚八点狼人杀
（引用一条消息）转发到群 433397830
确认 123456
取消 123456
取消 ad_xxx
撤回 刚才
撤回 ad_xxx
动作 ad_xxx
待批
同意 123456
同意 123456 3
拒绝 123456
状态
健康
未知发送
失败发送
```

- `发到群` / `转发到群` 只创建**待确认动作**，回复预览和 6 位确认码；不会直接发送。
- `确认` 后逐目标发送，完成后私聊回报每个群的结果。部分内容已送达时目标标为 `partial`，账本按 unknown 处理，不会自动重发；未确认的动作也可用 `取消 ad_xxx` 放弃。
- `撤回` 只撤机器人自己在目标群发的消息，且要求本地 `messages` 表能证明 `self=true`；超过 5 分钟窗口会提示到群内手动撤回。
- `待批` 汇总插件待批、入站好友申请、待确认发送动作；插件/好友用短码批准或拒绝。原有 `同意 ap_xxx` 仍兼容。
- `同意 <码>` 默认批准 1 次，可带 1–20 的次数。
- `状态`/`健康` 只读，不展示 token、API key 或配置原文；`状态` 会给出待确认/未完成的动作数量，`动作 ad_xxx` 可查看单个动作的逐目标结果。
- 控制台核对 unknown 外发后，会同步回写对应管理员动作的目标结果，核对为已发送的消息随后可撤回。

## 自然语言

管理员私聊里说“把这条消息发到群里”，模型可以调用 `admin_send` 生成发送计划（视频请用聊天记录卡片，不单独支持视频文件）。
工具**只创建待确认动作**，不会发送；机器人回复预览后，仍需管理员用固定命令
`确认 <码>` 执行。

白名单只有一个群时，`admin_send` 可以省略 `target`；多个群必须指定群号或完整群名。

支持的内容项：

```json
[
  { "type": "text", "text": "今晚八点狼人杀" },
  { "type": "image", "messageId": "123" },
  { "type": "forward", "messageId": "123" },
  { "type": "file", "url": "https://example.com/a.txt", "name": "a.txt" },
  { "type": "voice", "url": "https://example.com/a.mp3", "seconds": 3 },
  { "type": "aiVoice", "text": "晚上好" }
]
```

## 群内只读命令（可选）

默认关闭。在「设置 → 群管理 → 群内管理员只读命令」开启，并可限定群号。只认全局管理员本人，
且必须是真实收到的群消息；引用/转发/卡片里的文字不算命令，补课历史（backlog）也不会执行。

可用命令：

- `状态`：运行模式、OneBot、入站积压、出站未知、当前游戏。
- `行为卡`：回复概率、对话模式、长期记忆、群游戏与外部写开关的说明，不含密钥/配置原文。
- `最近决策`：最近一轮为什么回/不回、命中原因、档位与概率。
- `结束游戏`：结束本群当前由系统主持的游戏。

`同意/批准/拒绝/确认/取消` 等高权限动作仍只接受管理员私聊；群内命令回复是公开的，
不要用它发送审批短码或敏感内容。

## 安全边界

- 仅 `kind=private` 且 `chatId === admin.ownerUin`；群聊、其他私聊完全看不到管理员工具。
- 群内只读命令是独立的固定入口，默认关闭；同样只认 `admin.ownerUin`，不经过模型。
- 固定命令只处理真实收到的消息，忽略 `message_sent` 回显。
- 模型永远不能直接确认；确认码只在管理员真实回复里生效。
- 确认码 6 位、2 分钟过期、最多 5 次尝试、只存哈希；同一时间只保留一个待确认发送动作。
- 每个目标独立 `EffectLedger`，一个群 unknown 不影响其他群；不会自动重发 unknown。
- 自然语言工具可一次传多个目标群（最多 5 个）；固定命令一次一个群。单次最多 10 个内容项、4000 字；目标之间串行并留间隔。
- 发送/撤回/审批均写审计，审计不存完整正文或确认码明文。
