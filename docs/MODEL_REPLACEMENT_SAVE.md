# 模型替换链独立保存

主模型、语音转文字、语音回复（TTS）、图片生成四条链各自保存。
每条链的按钮只提交本链开关、模型列表、顺序及版本号，不保存普通设置或其他链。
页面底部“保存设置”不提交替换链；后端普通设置接口也会忽略旧客户端传入的 modelReplacement。

- 未修改直接保存：保留推进位置、最近切换记录及版本号。
- 修改列表/顺序或从关闭重新启用后保存：只重置该链到第一个有效选择。
- 只关闭后保存：保留位置；已选错误条件的自动替换和末项自动关闭逻辑不变。
- 后台已推进/其他页面已修改：旧版本保存返回 409，不覆盖进度，保留当前草稿。
- “重新读取此链”仅重新读取这一条链；如有未保存改动会先确认，不丢弃其他草稿。
- 普通设置与替换链使用独立的未保存标记，离开页面仍有确认保护。

## 接口

`POST /api/model-replacement`，沿用控制台鉴权。
请求字段严格限制为 `channel`、`enabled`、`entries`、`revision`。
channel 只接受 `chat` / `asr` / `tts` / `imageGen`；不允许提交执行游标或其他设置。
触发条件模块使用同一个接口，但请求仅为 `{ channel, triggers, revision }`；
`triggers` 必须包含 `http402`、`http403`、`quota429`、`http401` 四项布尔值，不能同时提交模型列表/开关。
保存规则不重置游标或最近切换记录，模型列表保存也不会修改规则。
响应为 `{ ok, channel, chain }`，只回填对应链，不重建整页。

此改动需要同时更新前端和后端；不能只同步 ui/。
